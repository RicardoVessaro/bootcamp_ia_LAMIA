# Anotações da Aula: Probability Density Function; Probability Mass Function

### Função de Densidade de Probabilidade (_Probability Density Function_)

É utilizada em dados númericos continuos em intervalos de dados, na distribuição de uma população.

As proabilidades são divididas em intervalos por se tratarem de dados contínuos, 
e não sobre um valor específico pois a propabilidade exata é infinitivamente pequena. 

No caso da distribuição normal utilizada nas aulas temos as seguintes probabilidades:

```
0.1%    2.1%    13.6%   31.4%  |  31.4%     13.6%    2.1%       0.1%
 |       |       |        |    |    |         |       |
    -3σ     -2σ     -1σ        0          1σ      2σ      3σ
                             média
```

- 0.1% dos dados estarem entre -3σ e -2σ da média;
- 2.1% dos dados estarem entre -2σ e -1σ da média;
- 34.1% dos dados estarem entre -1σ e a média;
- 34.1% dos dados estarem entre 1σ e a média;
- 2.1% dos dados estarem entre 2σ e 1σ da média;
- 0.1% dos dados estarem entre 3σ e 2σ da média;

Isso é a Função de Densidade da Probabilidade representada por uma linha na 
distribuição normal, a probabilidade de um dado cair em desses intervalos.

### Função de Massa de Probabilidade (_Probability Mass Function_)

Quando se trata de dados numéricos discretos nós tempos a função de massa de
probabilidade, pois aquela chance infinitivamente pequena não existe no caso
dos dados discretos. Logo ela é representada pelo histograma e não pela linha.

```
                    _
0.3                 
0.25
                _       _
0.2
0.15
0.1         _               _
0.05
        _                       _
0
        0   1   2   3   4   5   6   
```

Neste caso 3 tem a maior probabilidade (acima de 30%). Em seguida 2 e 4, depos 1 e 5
por fim 0 e 6, por se tratar de uma distribuição normal.
