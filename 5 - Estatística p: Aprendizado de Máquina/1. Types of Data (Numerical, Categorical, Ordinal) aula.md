# Anotações da aula: 1. Types of Data (Numerical, Categorical, Ordinal)

Apresenta os tipos de dados que podemos estar lidando quando se fala de _Data Science_.

Dependendo o tipo de dado o tipo de técnica utilzizada pode variar.

Principais tipos de dados:
- `Numerical` (numérico)
    
    Medida quantitativa, que se pode medir, altura, valores de ações com um número. 

    Podendo ser discreta (_discrete_), compras feitas ao ano, quantas vezes uma das possibilidades disponíveis aconteceu, etc. 

    Podendo ser contínua (_continuous_), tem um intervalo infinito de possibilidade como por exemplo a altura das pessoas, pode 
    ser qualquer valor dentro do intervalo. Quanto tempo uma atividade demora para ser realizada, entre outras.

- `Categorical` (categórica)

    Descrições que não tem significado matemático, gênero, estado, tipo de prato, respostas entre sim e não. Podem ser identificadas
    por número mas esse número não tem um significado matemático.

- `Ordinal` (ordinal)

    Uma mistura onde utilizamos categorias mas essas categorias tem uma relação matemática entre si para definir algo como qualidade
    de um filme utilizando quantidade de estrelas de 1 a 5, ou perguntas onde 1 é não concorda e 5 é concorda e a concordância vária.

Exemplos de dados para os tipos:

- Quantidade de gás no butijão = Númerico contínua.
- Nota para saúde onde 1 é ruim e 4 excelente = Ordinal.
- Etnia dos colegas de classe = Categórico.
- Idade = Númerico, podendo se discreto se for  35,40, 45, 50 ou se fosse mais preciso Anos, mês e dias poderia ser contínuo.
- Quantidade gasta na loja = Númerico contínuo.
